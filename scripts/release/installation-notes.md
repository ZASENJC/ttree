## 安装与使用

**Mac：** 打开 Universal DMG，将 TTREE 拖入“应用程序”。若首次打开被阻止，请在“系统设置 → 隐私与安全性”选择“仍要打开”。截图 OCR 需授予“屏幕与系统音频录制”权限，授权后完全退出并重启 TTREE。包使用固定社区证书签名，未经过 Apple 公证；同一证书用于维持更新前后的录屏权限身份。

**Windows：** 解压 x64 ZIP 到固定目录，运行 `TTREE/TTREE.exe`，按 `Ctrl+Shift+Space` 呼出窗口。包未使用商业代码签名证书，可能触发 SmartScreen，请核对官方来源及 SHA256SUMS。OCR 依赖系统对应语言的文字识别组件。

翻译和对话共用业务库，分别提供 AppKit / Win32 原生界面。内置模型首次使用时独立下载。当前纯 Rust 版本使用手动下载替换升级；更新归档及签名为旧客户端保留。配置中的 API Key 当前保存在本机 JSON，请勿分享配置文件。
