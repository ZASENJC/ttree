## macOS installation

TTREE is community-signed with the project's pinned open-source certificate. It is not notarized by Apple.

1. Download the DMG and drag TTREE to Applications.
2. If first launch is blocked, open System Settings > Privacy & Security and choose Open Anyway.
3. Trigger screenshot OCR and allow Screen & System Audio Recording.
4. Fully quit and reopen TTREE after granting permission.

All releases use the same certificate-pinned designated requirement so Screen Recording permission can persist across updates. Install TTREE only from this repository's Releases.
