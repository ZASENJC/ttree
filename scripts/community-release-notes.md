## macOS installation

TTREE is an open-source community-signed app. It is not notarized by Apple.

1. Download the DMG and drag TTREE to Applications.
2. On first launch, macOS may block the app. Open System Settings > Privacy & Security and choose Open Anyway.
3. Trigger screenshot OCR once and allow Screen & System Audio Recording.
4. Fully quit and reopen TTREE after granting permission.

All releases use the same certificate-pinned code identity so Screen Recording permission can persist across updates. Do not install builds from untrusted forks under the TTREE bundle identifier.
