# TTREE FLOW / v2

保留 v1。v2 为 30 秒、1920×1080、30 fps，Mac 版组件重绘，非截图或录屏。时间压缩呈现交互，下载速度及文本内容均为演示。

| 时间 | 展示内容 |
| --- | --- |
| 0–3.75 秒 | TTREE 标识与品牌主张，鼓点建立 |
| 3.75–7.50 秒 | 输入英文、免费翻译返回、AI 中文逐字流式输出、双译文对照 |
| 7.50–11.25 秒 | 截图快捷键、框选英文、正在识别、识别完成、结果回填至翻译页 |
| 11.25–15.00 秒 | AI 对话、历史对话条、新对话入口、用户追问、助手流式回答 |
| 15.00–18.75 秒 | AI 翻译设置、启用开关、HY-MT 接入、4-bit 精度、环境检测、下载进度、启动就绪 |
| 18.75–22.50 秒 | AI 对话设置、兼容接口及遮罩密钥、切换 Ollama、本机地址、探测模型、提示词、保存配置 |
| 22.50–26.25 秒 | 快捷键，再切至通用：透明度、开机启动、OCR 换行合并、检查更新；Esc 与置顶文案 |
| 26.25–30.00 秒 | 返回品牌空间及项目地址，与开头相接 |

功能核实：apps/macos/src/state.rs 中四个设置分区、HY-MT 控件与服务状态，AiTranslateDelta / ChatDelta 流式文本事件以及顶部历史选取条。OCR 仍为原生框选与 Vision，本片选择框只为重绘动效，不改动产品。

配乐：synth-v2.py 原创 128 BPM、16 小节电子乐。数学合成鼓、低音、琶音与铺底，无外部采样，沿用仓库 MIT。3.75 秒双小节镜头同步，尾音环形折回。无实际听音能力，不宣称听感验收通过。

制作源码 src/v2.tsx；执行 bash render-v2.sh。最终文件 out/TTREE-30s-v2.mp4。QA 数据 qa-v2-results.json；六格预览在 docs/images/promo-loop-30/storyboard-v2.jpg。
