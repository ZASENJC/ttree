# TTREE · FLOW / 30 秒循环宣传片

1920 × 1080，30 fps，900 帧。Mac 界面组件重绘；不使用截图或录屏，不使用 Apple 标识。品牌图标来自项目 `assets/icons/icon.png`。界面结构依据实际 Mac 版以及 `apps/macos/src`；翻译、OCR、AI 能力依据根 README。渲染示意不是功能操作实录。

## 可编辑制作

- `src/index.tsx`：镜头、Mac 窗口组件、排版与逐帧动画。
- `synth.py`：原创 96 BPM 氛围电子配乐，12 小节，48 kHz 双声道；无第三方采样。
- `public/flow-original.wav`：可直接交付和剪辑的无损音乐。
- `out/TTREE-30s.mp4`：最终 H.264 / AAC 成片。
- `../../docs/images/promo-loop-30/cover.png`：封面预览。

安装：`npm ci`。预览：`npm run studio`。渲染：`bash render.sh`；可附加 `--browser-executable=/path/to/chrome`。依赖锁定于 package-lock.json。Node 22、FFmpeg、Python 3；若本机 Python 管道编码异常，直接运行文件。

## 脚本

0–4 秒：品牌图形在干净空间中呼吸，快捷键与窗口逐渐出现。
4–10 秒：轻轻唤起，接着思考；Mac 原生结构窗口从透视空间推近。
10–17 秒：两份译文，一眼对照；连续推进窗口并放大译文。
17–23 秒：截图识字与 AI 对话文案，选择框动效作为能力示意。
23–28 秒：品牌主张及项目地址。
28–30 秒：回到同一品牌空间，与下一轮连续相接。

## 音乐来源与许可

曲名：FLOW / TTREE 30。为此次项目用数学振荡器原创合成，无商业歌曲、外部录音、采样包或订阅。合成源码、生成的音乐及本目录原创动画沿用仓库 MIT 许可，可随成片复制、修改和分发。项目原有品牌资产保留原项目权利。配乐无需署名外部作者。

## 循环设计

900 帧构成一个周期，首尾不人为复制同一帧；品牌呼吸、光场及页脚进度由 900 帧周期函数驱动。中段场景在边界前完全退场，最后一帧至第一帧保持正常一帧运动距离。音乐事件及混响式衰减尾音按 30 秒环形缓冲折回，持续音使用周期内整数振荡次数。最终 QA 数据见 `out/qa.json`，连播检查文件为 `out/loop-check-60s.mp4`。

播放器是否能无间隔重复单个 MP4 取决于播放器的缓存与循环实现；成片内部素材接缝与两轮拼接文件已分别检查。
